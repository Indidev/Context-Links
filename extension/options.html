Rules

Each rule matches pages whose URL tests true against a regular expression. Every shortcut inside a matching rule is shown in the floating panel. Add conditions to also exclude a pattern, or to match an alternate pattern instead (e.g. match google.com/.* except google.com/maps, or show the same shortcuts on google.com/search OR bing.com/search).
